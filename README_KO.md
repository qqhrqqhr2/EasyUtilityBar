# EasyUtilityBar

와우 포에버(Interface 16001)용 유틸리티 단축바 애드온입니다. 가방의 사용 아이템, 전문기술, 직업 보조 스킬을 분류별로 모아 한 번에 보여줍니다.

## 기능
- 폭탄, 기계공학, 물약, 음식·음료, 붕대, 야영, 이동(귀환석·탈것), 퀘스트, 착용 장비(사용 효과), 기타 아이템 분류
- 전문기술, 변신·태세, 직업 보조 스킬(부활·귀환·포탈·축복 등)
- 음식·물약·붕대 최고 등급만 표시, 위로 펼치기
- 분류 접기/펼치기 상태 저장, 아이콘 크기·한 줄 개수, 불투명도, 마우스 올릴 때만 표시
- 아이콘 개별 숨기기 (제목에 마우스를 올려 테두리를 띄운 뒤, 잠금 해제 상태에서 아이콘의 x 클릭)
- 한국어, 영어, 중국어(간체/번체), 러시아어, 독일어, 스페인어

## 사용법
- 설정: `/eub` 또는 단축바 제목에 마우스를 올린 뒤 톱니바퀴
- 이동: Ctrl + 제목 왼쪽 드래그
- 명령어: `/eub lock`, `/eub show`, `/eub hide`, `/eub refresh`
